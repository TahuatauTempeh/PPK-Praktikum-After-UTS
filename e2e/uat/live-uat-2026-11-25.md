## E2E perangkat dengan backend emulator

Perintah:

```bash
ALLOW_REAL_DEVICE=1 TIER=full ANDROID_SERIAL=RRCX904MVLX \
MANIFEST=e2e/android/manifest.device.tsv \
bash e2e/android/run.sh
```

Hasil: 6/6 flow lulus, lalu `Verifikasi E2E Android lulus (full, manifest.device.tsv)`.

| Flow | Durasi | Hasil |
|---|---:|---|
| asisten-kehadiran | 33 dtk | Lulus |
| izin-lokasi-ditolak | 32 dtk | Lulus |
| layanan-lokasi-mati | 36 dtk | Lulus (setelah `scrollUntilVisible` untuk layar A55) |
| sesi-tanpa-lab | 40 dtk | Lulus |
| izin-native | 1 mnt 11 dtk | Lulus |
| kesan-pesan-native | 55 dtk | Lulus |

Flow radius (`presensi-dalam-radius`, `presensi-luar-radius`) tidak dijalankan
di A55 karena provider lokasi uji selalu ditandai `mocked=true` dan aplikasi
menolaknya dengan `Lokasi palsu terdeteksi`. Flow itu tetap dijalankan di
emulator, tempat `adb emu geo fix` tidak ditandai mock.

`UAT-ATT-04`/`izin-lokasi-dicabut` tetap manual/parsial: `pm revoke` pada A55
menghasilkan state `denied`, bukan `blocked`.

- test provider `gps`/`e2e_gps` dihapus

`autofill_service` perlu dipilih ulang oleh pengguna lewat Pengaturan jika
sebelumnya memakai layanan autofill tertentu.
